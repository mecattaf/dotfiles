# dsh-domicile

Read-only explicit-desktop introspection. Project Imagine's real reducer and
final Stage geometry; never invent a parallel window manager. Server-owned
DSH sessions remain distinct from client desktop/window/workspace identities.
Inter-device transport is strict Tailscale SSH with a known host alias, no
LAN/public fallback. No client DSH Host, provider credentials, desktop HTTP
listener, generic execution capability, or generated-card authority.

Do not edit Imagine Desktop/AgencyKeys/Nix: launch_recovery owns integration.
Root reviews before live desktop attachment or production DSH registration.
Source and isolated proof work is authorized. Heavy/runtime tests go to
strix-coordinator via reviewed fleet-tailnet helper and target runtime-test;
never strix-worker. No commits/remotes/publication, Herdr/user-manager/reboot,
Projects CLI, uncodixfy, prohibited history or custom gamma work.
