# Frozen Imagine migration payload

This directory preserves the production payload from before the standalone
`agency-agency/imagine` input. It is migration history, not an active flake
input or another maintained shell. Production and shell checks use the pinned
shared repository. Do not add new shell changes to this copy.

The snapshot came from the Zenbook's running 8 November 2026 source, followed
by client-supplied display-temperature support through the public Domicile
API. Its MIT notices and extraction provenance remain preserved here. The
active stylesheet derives from Manganese75708d763800. Historical proof logs
are dated evidence rather than current validation.

Current shared source, compatibility and contribution guidance live in
[agency-agency/imagine](https://github.com/agency-agency/imagine). The fleet
entry and device policy remain in `home/dot_config/domicile/domicile.tsx`.
