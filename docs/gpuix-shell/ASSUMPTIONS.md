- ARCHITECTURE: a headless `gpuix-shell daemon core` (unit `gpuix-shell-core`) owns `shell.sock`, the registry/router, Sway IPC, the herdr poller, status D-Bus clients, the clipboard store and the surface supervisor. It is not in the rail (SCOPE S-002 rev) because rail hide/expand are process exits and the router must survive GPU faults (ARCHITECTURE §3.1, §22 C-2).
- ARCHITECTURE: toggled overlays are spawned by the core supervisor, not by the CLI (SCOPE S-001 rev). It handles one exclusive overlay at a time, closes on focus loss, closes on ready when a toggle was pressed twice, ignores repeat toggles within 150 ms, and supports an optional warm spare (§3.3, §22 C-3).
- ARCHITECTURE: `shell.sock` canonical wire = JSON-RPC 2.0 messages framed as NDJSON (one per line), method `<domain>/<verb>`. Vicinae's 4-byte length framing is also accepted on the same socket via a 3-byte sniff (`{` + third byte ≠ 0x00 ⇒ NDJSON; length frames capped below 64 KiB), P1 (§4.1, §22 C-1).
- ARCHITECTURE: exit codes 0 ok / 1 failed-refused-dismissed / 2 usage / 3 shell or daemon not running / 69 unavailable, with a fixed JSON-RPC error-code mapping (§4.3). This matches KEYS §7.8 and SCOPE S-002.
- ARCHITECTURE: singleton per surface = `$XDG_RUNTIME_DIR/gpuix-shell/<name>.sock`. Bind is the lock: probe with a 1 s ping, else unlink and listen, with no flock (Bun has none). The session token is sha256($SWAYSOCK)[:16] and rejects sockets left over from another Sway session (§3.2).
- ARCHITECTURE: surfaces get their first-frame data from a 0600 spawn-payload file named by env `GPUIX_SHELL_SPAWN`, never through stdin (stdin is ignored so GPUIX automation stays off) (§3.3).
- ARCHITECTURE: package layering keeps the task's `src/core/<area>` names (sway-ipc, herdr, dbus, theme, fonts, registry, socket, logging) for the PURE halves.
