## Defaults the build proceeds on (object here or they ship)

- Output: table when stdout is a TTY, JSON when piped — zero flags.
- Verb surface additions from the transfer brief: `unarchive` (soft archive
  needs a restore path) and `crm doctor` (integrity/FTS/journal-mode drift
  repair). Everything else stays exactly the frozen SPEC surface.
- `edit` reuses the `add` flag set as a partial patch; unpassed flags
  untouched; no-op edits succeed silently without touching `updated_at`.
- `PRAGMA foreign_keys=ON`; `delete --confirm` on a still-referenced row
  fails exit 4 pointing at `archive`; archiving an org does NOT cascade to
  its contacts.
- `log` without `--date` = today, local time. `init` is idempotent, creates
  db + notes/crm/ + transcripts tree, and is the ONLY verb that creates a
  database — any other verb on a missing db errors naming the resolved path.
- `ls`: interactions newest-first, orgs/contacts alphabetical.
- `--source`/`--detail` repeatable, joined ' || '; duplicate `--with` refs
  silently dedup; usage errors exit 1; `contact add` space-joins multi-word
  names (no batch add).
- DDL stays frozen; migrations embedded in the binary keyed on user_version;
  timestamps generated in Go (RFC3339 UTC), never datetime('now').
- Transcript paths notes-repo-relative, validated to exist, never copied.
- The binary never touches git; commits come from the session/skill (a
  post-write hook is the seam if wanted later).
- Transcription: manual-trigger tally flow invoking the rooted VibeVoice-ASR
  snapshot directly (service packaging stays future work); full WAV →
  diarized transcript path must be tested before Friday's call.
- Build mechanics: one flow per issue, sequential, fail-fast.
