# kitty layer (home/dot_config/kitty)

This folder is the terminal layer of the client seat. home/home.nix links it as a whole directory out of store symlink to `~/.config/kitty` (REPORTED, home/home.nix RAW list and the comment beside `kitty-scrollback-nix.conf`), so a new file here is live on the next login without a rebuild. Nothing in this folder was applied or run on 2026-10-22.

| file | holds |
|---|---|
| `kitty.conf` | shell fish, window and clipboard settings, remote control, the four includes, the herdr projector contract |
| `font.conf` | AnthropicMono Nerd Font by family name, size 16.0, the six font rulings that still hold |
| `maps.conf` | every `map` and `mouse_map`, each under a `## group \| verb \| doc` line, and the reserved chords for herdr and Sway |
| `open-actions.conf` | text and code files open in nvim in a new OS window (unchanged) |
| `ssh.conf` | `kitten ssh` per destination options, fish as the remote login shell (two line number pointers into kitty.conf replaced by names, comments only) |

Include order in kitty.conf, top to bottom: `font.conf`, `${HOME}/.config/kitty-scrollback-nix.conf` (generated by home/home.nix, defines the `kitty_scrollback_nvim` alias), `maps.conf`, `${HOME}/.config/theme/kitty.conf` (colours, last so it wins). The two external include lines are byte for byte the old ones.

## Binding grammar

Every map line in maps.conf has one comment directly above it matching

```
^## ([a-z][a-z0-9 ]*) \| ([a-z][a-z0-9 ]*) \| ([^|]+)$
```

MEASURED on 2026-10-22 with a Python check over maps.conf: 5 map lines, 0 missing or unparseable. kitty.conf and font.conf hold 0 map lines. The keymap generator (tools/keymap, another lane) was not run against this file.
